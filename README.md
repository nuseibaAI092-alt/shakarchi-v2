# شیرینی شەکەرچی (Shakarchi Bakery)

A modern, fully responsive e-commerce frontend for a traditional Kurdish bakery. This project was built from scratch to provide a seamless, localized shopping experience for customers to browse and order traditional sweets.

## ✨ Features

*   **Kurdish RTL Support:** Fully localized Right-to-Left (RTL) layout optimized for the Kurdish Sorani language.
*   **Dynamic Menu:** Products are rendered dynamically using JavaScript arrays, making it easy to add or update items.
*   **Shopping Cart:** A fully functional cart that uses `localStorage` to save items, track quantities, and calculate the total price—even if the user refreshes the page.
*   **WhatsApp Checkout:** A custom checkout system that automatically generates a formatted WhatsApp message with the customer's order details and total price.
*   **Persistent Dark Mode:** A theme toggle that remembers the user's preference across page reloads using `localStorage`.
*   **Responsive Design:** Optimized for mobile, tablet, and desktop viewing using CSS Grid and Flexbox.
*   **Custom Animations:** Includes hover effects, fade-ins, and dynamic UI feedback (like the "+" button turning into a "✓").

## 🛠️ Technologies Used

*   **HTML5:** Semantic structure and forms.
*   **CSS3:** Custom properties (variables), Flexbox, CSS Grid, Media Queries, and transitions.
*   **Vanilla JavaScript (ES6+):** 
    *   DOM Manipulation (creating elements dynamically)
    *   Event Delegation
    *   LocalStorage API
    *   Fetch API (for random quotes)
    *   Array methods (`map`, `forEach`, `find`, `filter`)
